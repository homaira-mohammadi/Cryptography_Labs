# Cryptography Lab — Classical Encryption Techniques

Jupyter notebook implementations for Week 2 labs covering classical encryption: symmetric cipher models, cryptanalysis, and substitution/transposition ciphers.

## Contents

| Notebook | Topic |
|---|---|
| `Lab1_Symmetric_Cipher_Model.ipynb` | XOR-based symmetric cipher model |
| `Lab2_Cryptographic_Systems.ipynb` | Sender/receiver simulation, confidentiality & integrity |
| `Lab3_Cryptanalysis_Bruteforce.ipynb` | Caesar cipher + brute-force attack |
| `Lab4_Encryption_Scheme_Security.ipynb` | Keyspace analysis, weak vs. strong ciphers |
| `Lab5_Caesar_Cipher.ipynb` | Caesar cipher encrypt/decrypt/brute-force |
| `Lab6_Monoalphabetic_Cipher.ipynb` | Random substitution cipher + frequency analysis |
| `Lab7_Playfair_Cipher.ipynb` | Playfair cipher (5×5 matrix, digraphs) |

## Requirements

```bash
pip install numpy matplotlib cryptography
```

## Usage

Open any notebook in Jupyter or VS Code and run all cells:

```bash
jupyter notebook
```

Each notebook is self-contained — encrypts/decrypts a sample message and prints the output inline.
